## Sobre o Projeto:
O DB READER é uma aplicação de **NL2SQL** (Natural Language to SQL) que utiliza uma LLM local via Ollama para transformar perguntas em linguagem natural diretamente em consultas SQL, executar análises em bancos de dados relacionais e gerar respostas estruturadas com exportação de dados.
O objetivo do projeto é simplificar o acesso a informações corporativas e técnicas, permitindo que usuários interajam com bancos de dados usando conversas em texto natural, integrando Inteligência Artificial com manipulação de dados em Python e Pandas.

## Instalação e Execução:

Clone o repositório:
```bash
git clone https://github.com/seu-usuario/DB_READER.git
```
Acesse a pasta do projeto:
```bash
cd DB_READER
```
Instale as dependências:
```bash
pip install -r requirements.txt
```
Execute a aplicação:
```bash
python main.py
```
